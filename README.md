# 서울 지역구 우리동네 베스트 대출 도서목록 10선
국립중앙도서관 API를 활용하여 서울시 내 지역구 도서 베스트 대출 정보를 기간 별로 가져오는 사이트



<br/><br/>
## 선정 이유

### 문제인식
- 문해력이 더 이상 어린에게만 문제가 되지 않는다는 문제 인식 파악(사회적 이슈)
   참조 : https://www.hani.co.kr/arti/society/society_general/1127253.html

### 접근 방식
1. 당근 마켓에서 하이퍼로컬(슬세권)으로 비지니스 모델 변경함으로써 지역 상권에 대해 관심이 생김
   참조 : https://plus.hankyung.com/apps/newsinside.view?aid=202304281687Q&category=&sns=y

2. 문해력 + 지역 상권  => 지역모임 + 관심사 중 쉽게 접할 수 있는 소재
3. 소재 선정 : 전 회사가 도서관 홈페이지를 제작하는 회사라 도서

### 대상
- 지역기반으로 생활반경을 가진 사람들 : 학부모 + 50+(시니어)

### 결론 
- 지역구 도서관 베스트 대출 도서목록을 활용한 관심사 공유 및 문해력 해결을 위한 모임 활성화
  
```{학부모 + 시니어(50+)} + 지역 상권 + 도서```
